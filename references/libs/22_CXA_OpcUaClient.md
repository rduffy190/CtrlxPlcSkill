# 22 CXA_OpcUaClient

## 22.1 Introduction and overview

The CXA_OpcUaClient library implements an OPC UA Client based on the
specification PLCopen OPC-UA Client for IEC61131-3.
Function blocks are provided to establish and cancel connections, to read and
write nodes and to call methods.
To use the library, install the OPC UA Client app and the PLC app.

Documentation
For the documentation on each single function block, go to the
“Documentation” tab of the selected function block in the ctrlX PLC Engi‐
neering library manager.
The “Documentation” tab includes the following information:
● Special features on the function blocks
● Structures of the function blocks
● Enumerations of the function blocks
