# 24 CXA_OpcUaCommon

## 24.1 Introduction and overview

The CXA_OpcUaCommon library provides shared data types and POUs to use
the CXA_OpcUaClient and CXA_OpcUaServer libraries.

Documentation
For the documentation on data types and POUs, go to the “Documentation”
tab of the selected data type or POU in the ctrlX PLC Engineering library
manager.
