# 26 CXA_OpcUaServer

## 26.1 Introduction and overview

The CXA_OpcUaServer library provides function blocks for the OPC UA Server
of the control.
To use the library, install the OPC UA Server app and the PLC app.

Documentation
For the documentation on each single function block, go to the
“Documentation” tab of the selected function block in the ctrlX PLC Engi‐
neering library manager.
The “Documentation” tab includes the following information:
● Special features on the function blocks
● Structures of the function blocks
● Enumerations of the function blocks
