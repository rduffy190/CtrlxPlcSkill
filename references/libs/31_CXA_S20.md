# 31 CXA_S20

## 31.1 Introduction and overview

The library CXA_S20 describes the access options of the IEC program on the
S20 system using function blocks.
The function blocks are interface-compatible with the function blocks from
the RIH_IndraControl_S20 library.
The S20 system is used in ctrlX CORE controls with S20 bus couplers and S20
modules.
Available functions:
●   Access to PDI objects
●   Diagnostics
●   Type plate
●   Normalizing input/output data
●   Configuration

## 31.2 Acyclic communication (Acyclic Communication)

### 31.2.1 IH_S20ComConfiguration

Sample program
The sample program is used to create a communication handle for S20 func‐
tion blocks "*Type02" with the S20BusHandle input.
The field bus used is defined at the input "BusType" using the variable "enBus‐
Type". The address or the name of the bus coupler is defined with "stBus‐
Config".
TRUE at the "Enable" input applies the configuration and the function block
generates the handle.
S20BusHandle applies to all S20 modules/function blocks at a bus master. A
bus master can be an S20 bus coupler with S20 modules locally connected in
series.

Example 1:
Step 1: Variable declaration at the S20-EC-BK, module at slot 1

Declaration:

PROGRAM Example_IH_S20ComConfiguration
VAR
// Function block instance
fbIH_S20ComConfiguration    : IH_S20ComConfiguration;
// Function block processing enabled( TRUE – once, edge-controlled )
bEnable                     : BOOL;
// TRUE: Function Block is working on its actual task
bInOperation                : BOOL;
// TRUE: Indicates an error
bError                      : BOOL;
// Class of error
ErrorID                     : ERROR_CODE;
// Detailed information about error
ErrorIdent                  : ERROR_STRUCT;
// Bus type selection
enBusType                   : IH_S20_BUSTYPE;
// Bus configuration parameters
stBusConfig                 : IH_S20_BUS_CONFIG;
// Bus handle
pS20BusHandle               : POINTER TO IH_S20_BUS_IDENTIFIER;

// EtherCAT Busmaster name
strBusMaster                 : STRING(100) := 'ethercatmaster';

END_VAR

Initialization of variables of the function block connected to the S20-EC-BK
and module at slot 1 in the program.

Program:

 // Bustype
 enBusType :=   IH_S20_BUSTYPE.ETHERCAT;

 // Bus Configuration
 // Address type
 stBusConfig.EtherCAT.AddressType := CXA_S20.CXA_EthercatMaster.IL_ECAT_ADDRESS_TYPE.ECAT_ETHERCAT_ADDRESS;
 stBusConfig.EtherCAT.BusMaster        := ADR(strBusMaster); // Bus master name
 stBusConfig.EtherCAT.SlaveAddress := 1001; // Address of the slave (bus coupler)

// IH_S20ComConfiguration FB Call
 fbIH_S20ComConfiguration(
Enable:= bEnable,
InOperation=> bInOperation,
Error=> bError,
ErrorID=> ErrorID,
ErrorIdent=> ErrorIdent,
BusType:= enBusType,
BusConfig:= stBusConfig,
S20BusHandle=> pS20BusHandle);

Initialization of variables of the function block connected to the S20-EC-BK
and module at slot 1 in the program.

Program:

// Bustype

 // Bus Configuration
 // Address type
 stBusConfig.EtherCAT.AddressType := CXA_S20.CXA_EthercatMaster.IL_ECAT_ADDRESS_TYPE.ECAT_ETHERCAT_ADDRESS;
 stBusConfig.EtherCAT.BusMaster        := ADR(strBusMaster); // Bus master name
 stBusConfig.EtherCAT.SlaveAddress := 1001; // Address of the slave (bus coupler)

 // Module Slot Number
 uiSlot    := 1; // Input your module slot here

// IH_S20ComConfiguration FB Call
 fbIH_S20ComConfiguration(
Enable:= bEnableComConfig,
InOperation=> bInOperationComConfig,
Error=> bErrorComConfig,
ErrorID=> ErrorIDComConfig,
ErrorIdent=> ErrorIdentComConfig,
BusType:= enBusType,
BusConfig:= stBusConfig,
S20BusHandle=> pS20BusHandle);

 // Example 1: Reading devicetype from the module
 // In this mode, FB will take care of PDI Index details. No need to input PDI index,
 // like 'OTHER_WRITE' mode

 enSetOpMode := IH_S20_OP_MODE.DEVICETYPE_READ; //Setting Operating mode to read DeviceType

 // Example 2: Writing PDI object '16#0080' with 'OTHER_WRITE' mode

 enSetOpMode := IH_S20_OP_MODE.OTHER_WRITE; //Setting Operating mode to PDI write

 stPDIIndex.EtherCAT.Index     := 16#0080; // PDI Index
 stPDIIndex.EtherCAT.SubIndex := 16#0000;
 // Fill your write data in to 'arIndexData' array & mention size of the
 //PDI object in 'SIZEOfIndexData' input

// Enable FB by making TRUE at 'bExecute' var

// IH_S20ComInterfaceType02 FB Call
 fbIH_S20ComInterfaceType02(
Execute:= bExecute,
Done=> bDone,
Active=> bActive,
Error=> bError,
ErrorID=> ErrorID,
ErrorIdent=> ErrorIdent,
S20BusHandle:= pS20BusHandle,
SetOpMode:= enSetOpMode,
Slot:= uiSlot,
PDIIndex:= stPDIIndex,
IndexDataAdr:= ADR(arIndexData),
SizeOfIndexData:= SIZEOF(arIndexData),
Timeout:= tTimeout,
NoOfRecBytes=> uiNoOfRecBytes);

## 31.3 Analog input modules (AnalogIO)

### 31.3.1 IH_S20AI4IUType02

Sample program
The sample program is used to configure and read the analog values of the
modules S20-AI-4-U and S20-AI-4-I. The analog values are normalized.
The field bus used is defined at the input "BusType" using the variable "enBus‐
Type". The address or the name of the bus coupler is defined with "stBus‐
Config". The module slot is defined at the "Slot" input.
TRUE at the "Enable" input applies the configuration and the function block
reads the current configuration of the module.

Example: Channel 1 to measure the analog voltage of 10 V, filter 30 Hz and 16
samples

module buffer or transferred to the buffer. If you expect 60 bytes for example
when reading, wait until the function block shows at least a value of 60 at the

● CXA_S20 S20_ErrorAdd
● CXA_EthercatMaster ErrorCodes
The CXA_S20 error codes are available in the Global Variable List
S20_ErrorAdd in the library CXA_S20.
For the CXA_EthercatMaster error codes, refer to the Global Variable List
